## Ausgewählte Projekte

### 🏒 Digitales Pausenspiel für die SCRJ Lakers
*Bachelorarbeit an der OST · im Zweierteam*

Ein interaktives Pausenspiel fürs Eishockeystadion. Zuschauerinnen und Zuschauer spielen per QR-Code live auf dem Smartphone mit, die Resultate erscheinen synchron auf dem Videowürfel. Es gibt drei Spielmodi: Quiz, Kreuzworträtsel und Bilderrätsel.

- Echtzeit-Synchronisation zwischen Admin-Bereich, Smartphones und Videowürfel über WebSockets
- Lasttest mit 1000 gleichzeitigen Nutzenden: P95-Antwortzeit nach AWS-Skalierung bei rund 223 ms

`React` `TypeScript` `NestJS` `Socket.IO` `PostgreSQL` `TypeORM` `Docker` `AWS`

➜ [Projektseite](https://jerielfrei.ch/work/digitales-pausenspiel-fur-die-scrj-lakers)

### 🖥️ BSL Support Dashboard
*Studienarbeit an der OST · im Auftrag der Berufsschule Lenzburg*

Ein zentrales Dashboard, das wiederkehrende IT-Support-Aufgaben bündelt: Passwort-Resets im Active Directory, PRTG-Server-Monitoring und die Überwachung von Power-Automate-Flows.

- Clean Architecture mit .NET 8 Web API und React, lauffähig im Browser und als Electron-Desktop-App
- Zweistufiges JWT-Berechtigungsmodell, das AD-Passwort liegt AES-verschlüsselt in der Session statt im Token
- Deployment mit Docker Compose, automatisierte Builds und Tests über GitLab CI/CD

`.NET 8` `EF Core` `React` `PostgreSQL` `Electron` `Microsoft Graph API` `LDAP`

➜ [Projektseite](https://jerielfrei.ch/work/bsl-support-dashboard) · [Publikation OST](https://eprints.ost.ch/id/eprint/1351/)
